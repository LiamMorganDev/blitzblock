# Changelog

## [1.3.0] - 2026-11-24

### Changed

- Match stats and charts use the available width, and empty promo slots on profiles collapse.
- Opening BlitzBlock again brings back the running window, including when another version is running.
- Filtered sessions show **BlitzBlock** as the taskbar window title and system tray tooltip.

## v1.2 — 2026-11-24

- Give filtered Blitz windows a purple BlitzBlock taskbar button and update Blitz's existing tray icon on supported builds.
- Show the installed BlitzBlock version beside the Blitz version in the header.

## v1.1 — 2026-11-24

- Check for stable BlitzBlock releases on launch, verify the download, then update automatically.
- Show BlitzBlock in the top-left corner when opened with the filtered launcher.

## v1 — 2026-11-24

- Single-file Windows installer with custom paths and an optional desktop shortcut.
- Start menu shortcut, Installed Apps registration, and uninstall support.
- Local Blitz promo filtering with a purple window icon when Windows accepts it.
